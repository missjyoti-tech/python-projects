
# Password Strength Checker 🔐

## About the Project
A beginner-friendly Python project that checks
password strength using five validation criteria.

## Features
- Checks password length (minimum 8 characters)
- Detects uppercase letters
- Detects lowercase letters
- Checks numeric digits
- Checks special characters
- Provides suggestions to improve passwords

## Technologies Used
- Python 3
- Conditional Statements
- Loops
- String Methods
- Lists

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

   python main.py

## Strength Levels
- Weak
- Medium
- Strong
